# Microsoft 365 Copilot: agentes y aplicaciones para el sector financiero

Curso aplicado para seleccionar mecanismos de asistencia, organizar información financiera, utilizar Finance Agent y desarrollar un agente personalizado con datos simulados. Los ejercicios conectan el análisis, la elaboración de informes y el seguimiento recurrente con resultados que pueden contrastarse con sus fuentes. La profundidad es introductoria y guiada; los recorridos de cuadernos, personalización, integración y automatización permanecen sujetos a la documentación y habilitación técnica pendientes.

## Lista de laboratorios

### Capítulo 1

- [3. Práctica 1. Selección de asistencia y síntesis de un caso financiero](Capitulo01/README.md#3-práctica-1-selección-de-asistencia-y-síntesis-de-un-caso-financiero)
  - Descripción: El participante sintetiza información sectorial simulada y prepara la estructura de una presentación y una ficha para vinculación de un cliente ficticio, identificando tareas en las que la asistencia puede ahorrar tiempo.
  - Duración estimada: 22 min
  - [Ver capítulo completo](Capitulo01/README.md)

### Capítulo 2

- [2. Práctica 2. Conciliación de datos simulados con Finance Agent](Capitulo02/README.md#2-práctica-2-conciliación-de-datos-simulados-con-finance-agent)
  - Descripción: El participante concilia datos simulados con Finance Agent y utiliza los resultados para completar y analizar un modelo financiero sencillo en Excel.
  - Duración estimada: 36 min
  - [Ver capítulo completo](Capitulo02/README.md)

### Capítulo 3

- [3. Práctica 3. Creación de un agente para investigación financiera con documentos de Microsoft 365](Capitulo03/README.md#3-práctica-3-creación-de-un-agente-para-investigación-financiera-con-documentos-de-microsoft-365)
  - Descripción: El participante crea un agente para investigar una operación ficticia de mercado de capitales, define sus instrucciones, utiliza documentos simulados y verifica el análisis contra las fuentes. Compara el resultado con el que obtendría mediante un prompt.
  - Duración estimada: 35 min
- [4. Práctica 4. Conector estándar de SharePoint en un agente](Capitulo03/README.md#4-práctica-4-conector-estándar-de-sharepoint-en-un-agente)
  - Descripción: Se muestra cómo un agente accede a documentos de SharePoint mediante un conector estándar, identificando permisos, autenticación y límites. No se realiza conexión a EMIS ni Capital IQ.
  - Duración estimada: 5 min
- [5. Práctica 5. Seguimiento financiero recurrente con revisión humana](Capitulo03/README.md#5-práctica-5-seguimiento-financiero-recurrente-con-revisión-humana)
  - Descripción: El participante configura, en una capacidad disponible y habilitada, una tarea de seguimiento recurrente de un fondo ficticio y revisa tres indicadores simulados antes de utilizar el reporte.
  - Duración estimada: 22 min
  - [Ver capítulo completo](Capitulo03/README.md)
